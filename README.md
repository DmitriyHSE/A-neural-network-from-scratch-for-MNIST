# A-neural-network-from-scratch-for-MNIST
Демонстрация знания архитектуры простых нейронных сетей

Задачи
- Написать модель нейронной сети без использования специализированных библиотек.
- Испытать работу написанной модели на датасете картинок рукописных цифр MNIST.
Требования
- Специализированные библиотеки, любые ML/DL фреймворки в коде модели нейронной 
сети использовать запрещается (напр. pytorch, tensorflow, keras, т. п.), в остальной части 
лабораторной -- по желанию.
- Использовать базовый класс Layer с методами forward() -- проход вперёд во время 
обучения/предсказания, и backward() -- проход назад во время обучения. Все «слои» 
(линейный y = xW + b, ф-ция активации, loss-ф-ция и т.п.) должны наследоваться от класса 
Layer.
- Использовать датасет MNIST для демонстрации работы модели нейронной сети. Можно 
использовать доступный вариант этого датасета из специализированных библиотек (напр. 
torchvision.datasets.MNIST).
- Показать примеры изображений (до предобработки и после, до аугментации и после), 
графики обучения, примеры предсказаний (верные и неверные).
- Сопровождать подробными комментариями в стиле «делаем …, потому что...», 
«следующий шаг мотивирован ... наблюдениями» и т.п
